# 收件箱

这里是个人知识库的统一输入入口。

随手想法、AI 对话、网页、论文、项目线索、会议记录和暂时无法分类的内容，都可以先放在这里。记录时不需要判断最终分类，也不需要填写完整模板。

## 最简单的记录方式

```markdown
# 一句话标题

- 记录日期：YYYY-MM-DD
- 来源：自己想到 / AI 对话 / 项目现场 / 会议 / 网页 / 论文 / 其他

## 原始内容

直接写下或粘贴内容。
```

标题、日期和来源能确定多少就写多少。信息不足时可以留空，不要因为整理成本而放弃记录。

## 让 Agent 处理

可以直接向本项目中的 Agent 说：

- “记一下这个想法：……”
- “把这段 AI 对话先收录。”
- “把这些材料沉淀进知识库。”
- “整理一下收件箱。”

Agent 会搜索已有内容，决定是补充现有文章、形成新条目、保留为待验证线索，还是继续暂存在这里，并同步维护[知识库索引](../索引.md)。

收件箱允许暂时凌乱，但不作为正式知识的证明。未经查证的说法、AI 输出和个人猜想在进入正式文章时，必须保留其证据边界。
