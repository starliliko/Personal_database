# 技术线索

技术线索是这个仓库的“待研究入口”。

在论文、GitHub、视频、评论区或技术讨论里看到一个陌生方案时，我不会马上把它写成正式知识，而是先保留原始来源、初步理解和不知道的问题。这样既不会忘记有价值的想法，也能避免未经验证的信息慢慢变成“好像已经确定的事实”。

## 当前线索

### [激光雷达反射贴多无人机定位](待研究/激光雷达反射贴多无人机定位.md)

这条线索来自 RM2027 技术讨论：在微型无人机表面布置高反射材料，尝试用固定雷达站的激光雷达进行检测和跟踪，并考虑用视觉补充姿态和身份信息。

目前还不知道远距离点数是否足够、反射材料在不同角度下是否稳定、多机如何保持身份，以及 Swarm-LIO2 原方案究竟能为这个思路提供多少依据。因此它仍是 L0 想法，而不是已验证技术方案。

## 线索接下来会去哪里

- 找到一手资料但仍缺实验时，可以形成初步技术知识；
- 能放进完整问题中分析时，可以参与技术案例；
- 被实际项目验证后，可以进一步形成工程知识；
- 多个案例反复出现相同结构时，才考虑总结为设计模式；
- 如果被证据否决，也会保留否决原因，避免以后重复踩坑。
