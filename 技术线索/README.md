# 技术线索

技术线索回答：“我刚发现了什么，以及接下来需要查什么？”

论文、GitHub 项目、视频、评论区、技术群或实际项目中出现的陌生方案，先在这里记录，不直接写入正式技术知识库。

## 状态

- **待研究**：保留原始来源、初步理解和未知问题。
- **已验证**：关键问题已经通过可靠资料或实验得到支持，可继续沉淀到知识库和案例库。
- **已否决**：已经找到不适用原因，并保留否决证据，避免以后重复踩坑。

初期直接在文件开头记录状态即可，不为了分类创建空目录。当前存在实际内容的 `待研究/` 目录除外。
