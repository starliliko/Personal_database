# 资源

这个目录用于保存仓库文章真正需要的架构图、示意图、公开数据和附件。

目前还没有独立资源。等某篇案例或知识文档需要图表时，再按内容建立子目录，不提前堆放来源不明的图片和文件。

## 可以放什么

- 自己绘制的系统架构图和流程图；
- 获得授权、可以公开使用的图片；
- 已经脱敏并具有跨项目复用价值的数据；
- 支撑公开分析的计算表格或附件。

## 不会放什么

- 项目专用的原始日志、配置截图和维护附件；
- 公司、客户、实验室或团队未公开资料；
- 无法确认作者和许可证的图片；
- 密钥、账号、内部网络信息和设备敏感信息。

具体项目资源仍应保存在项目仓库。这里保存的内容需要能够安全公开，并由正文明确引用。
