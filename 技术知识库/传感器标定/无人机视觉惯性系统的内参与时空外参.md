# 无人机视觉惯性系统的内参与时空外参

- 当前成熟度：L0 想法
- 来源：用户提供的 ChatGPT 对话“VIO LIO融合IMU”“解析无人机定位方案对比”
- 记录日期：2026-09-09
- 适用范围：单目、双目、多鱼眼相机与 IMU 组成的无人机视觉惯性系统

## 要解决的问题

标定的作用是建立传感器测量与物理世界之间的模型。视觉惯性系统需要同时知道每个相机怎样成像、各传感器怎样安装、它们何时测量，以及 IMU 噪声怎样随时间累积。

仅仅获得一组参数并不代表标定完成。参数还需要具有正确方向、单位、时间语义、适用分辨率和可重复的质量证据。

## 四类参数

### 相机内参与畸变模型

相机内参描述单个相机怎样把空间方向投影到像素，通常包含焦距、主点和畸变参数。普通针孔模型可写为：

\[
K=
\begin{bmatrix}
f_x&0&c_x\\
0&f_y&c_y\\
0&0&1
\end{bmatrix}
\]

鱼眼相机需要适合大视场的投影和畸变模型。等距投影、Kannala–Brandt 等可以作为候选关键词，但具体算法、标定工具和运行配置是否支持某种模型，必须按版本核对。

内参会受到分辨率、裁剪、缩放、对焦和温度等因素影响。不能把一个模式下的参数无条件用于另一个图像模式。

### 多相机空间外参

多相机系统需要知道每个相机相对于统一机体或参考相机的刚体变换：

\[
T_{B}^{C_i}=
\begin{bmatrix}
R&t\\
0&1
\end{bmatrix}
\]

其中旋转 \(R\) 描述朝向差异，平移 \(t\) 描述安装位置差异。四鱼眼系统不能只分别标定四个镜头，还要建立相机间外参和重叠视场关系。

### 相机与 IMU 的空间外参

VIO 需要相机与 IMU 之间的旋转和平移。快速旋转时，传感器到机体旋转中心的平移会形成杆臂效应，因此不能总是假设相机与 IMU 位于同一点。

外参矩阵的方向必须写清，例如“IMU 到 Camera”与“Camera 到 IMU”互为逆变换，名称相似但不能直接互换。

LIO 同样需要 LiDAR 与 IMU 外参；错误外参会破坏点云运动补偿和匹配。

### 时间外参与 IMU 模型

不同设备时钟之间可能存在偏移：

\[
t_{camera}=t_{imu}+\Delta t
\]

视觉惯性标定还需要描述 IMU 的零偏、噪声密度、随机游走、比例因子、轴间误差和温度影响。只填写一个 IMU 频率不足以建立可用的惯性模型。

## 四鱼眼加普通相机的职责划分

一种候选架构是：

```text
四路鱼眼 ─→ 大视场 VIO、定位或近场避障

普通前视相机 ─→ 高分辨率目标识别、跟踪或任务视觉

同步 IMU ─→ 视觉惯性高频传播

定位结果 ─→ 统一里程计接口 ─→ PX4 EKF2
```

普通相机不一定参与 VIO，四路鱼眼也不一定必须同时进入同一个估计器。系统设计前应明确每个相机是定位传感器、任务传感器、避障传感器，还是承担多个职责。

四鱼眼系统还要回答：

- 相邻视场是否重叠，是否需要跨相机特征关联？
- 所选算法是否原生支持多相机与鱼眼模型？
- 各相机是否同步曝光？
- 使用全局快门还是滚动快门？
- 总线、内存和处理器能否承担多路图像带宽？
- 单路遮挡、过曝或故障时如何降级？

## 参数错误的典型表现

| 参数问题 | 可能表现 |
| --- | --- |
| 相机内参或畸变错误 | 边缘重投影误差大、特征轨迹异常、持续漂移 |
| 相机间外参错误 | 跨相机几何不一致、转弯时误差增大 |
| Camera–IMU 旋转错误 | 姿态变化时视觉与惯性残差冲突 |
| Camera–IMU 平移错误 | 快速转动时出现系统性速度或位置误差 |
| 时间偏移错误 | 慢速似乎正常，高动态时明显失败 |
| IMU 噪声模型错误 | 协方差和零偏估计不可信、滤波器过度自信或迟钝 |
| 结构变形 | 撞击、温度或拆装后性能突然下降 |

这些现象并不唯一对应某一类参数问题，诊断时还要排除图像质量、振动、算法退化和时间戳错误。

## 从原型标定到产品标定

原型阶段常由研发人员手工采集标定板数据并生成参数；产品阶段还需要：

- 定义标定工装、动作范围和环境要求；
- 自动检查图像覆盖、姿态激励和数据质量；
- 为每台设备保存参数、质量指标和版本；
- 检测装配公差和异常设备；
- 明确维修、撞击、传感器更换后是否需要重标；
- 验证温度和长期使用对参数的影响；
- 建立重投影误差之外的系统级验收，例如轨迹误差和闭环飞行。

## 最小验证路径

1. 单独验证每个相机在目标分辨率下的内参与投影模型。
2. 验证多相机外参和重叠区域的重投影一致性。
3. 标定相机与 IMU 的旋转、平移和时间偏移。
4. 用独立数据验证参数，而不只检查标定数据集上的残差。
5. 比较慢速、快速旋转和振动条件下的估计残差。
6. 拆装或重复标定，评估参数重复性。
7. 将参数错误、时间偏移和结构变化作为故障注入项。
