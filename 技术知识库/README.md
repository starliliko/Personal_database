# 技术知识库

技术知识库回答：“某项技术本身是什么，它的输入输出、能力边界和工程代价是什么？”

这里不按想象提前建立大量空目录。只有一条技术线索经过查证，或者某项技术已经在案例中反复使用时，才创建对应分类和文档。

## 一篇技术知识应尽量回答

- 它解决什么问题；
- 基本原理和输入输出；
- 精度、频率、延迟和资源需求；
- 适用与不适用场景；
- 常见故障模式；
- 与相近技术的区别；
- 来源、实验和证据边界；
- 被哪些案例引用。
