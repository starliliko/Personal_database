# 设计模式库

设计模式库回答：“从具体项目中可以抽象出什么可复用的系统思想？”

设计模式不是某个产品或器件的推荐清单。它应说明问题背景、核心结构、适用条件、收益、代价、失效方式和已经出现过的案例。

例如，RM2027 案例可能产生“地面重计算与机载实时控制”“外部绝对定位与机载惯性传播”等模式，但在案例决策尚未验证前，暂不把它们写成成熟模式。

## 收录条件

- 已经在至少一个案例中形成明确架构；
- 能够脱离具体器件名称描述；
- 写清适用和不适用条件；
- 写清代价与故障模式；
- 明确哪些部分已经验证、哪些仍是推断。
