# 案例库

很多技术方案单独看都很合理，真正放进一个系统以后，却会同时受到规则、重量、算力、环境、通信和安全要求的限制。

案例库用完整问题保留这些上下文。这里不只展示“最后选了什么”，也尽量保留候选路线、放弃原因、风险和仍未回答的问题。

## 当前案例

### [RM2027微型空中机器人](RM2027微型空中机器人/README.md)

这是一次围绕微型无人机定位与系统架构的概念分析。

案例从几个现实矛盾出发：光流可能无法覆盖整个场地，视觉惯性导航存在重量和漂移压力，讨论认为超宽带不可使用，而外部定位又会带来遮挡、通信延迟和身份关联问题。

当前候选方向是把激光雷达、工业相机和重计算放在雷达站，把惯性测量、状态估计和实时控制留在机载端。这个方案仍处于 L0 想法阶段，适合阅读它的推理过程，不应当作已经验证的比赛方案。

## 案例会怎样沉淀

一个案例积累到一定程度后，可以产生三类内容：

- 技术本身的能力和边界，进入[技术知识库](../技术知识库/README.md)；
- 能跨项目复用的系统结构，进入[设计模式库](../设计模式库/README.md)；
- 尚未确认的陌生方案，继续放在[技术线索](../技术线索/README.md)中查证。

真实项目产生的具体配置、测试数据和维护结论仍保存在对应项目仓库，案例库只保留适合公开的技术分析。
