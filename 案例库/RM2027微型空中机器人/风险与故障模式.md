# 风险与故障模式

| 风险 | 可能原因 | 影响 | 当前应对思路 |
| --- | --- | --- | --- |
| 光流失效 | 低纹理、光照、高度或模糊 | 短时速度约束下降 | 质量检测和其他信息源 |
| 激光雷达目标丢失 | 遮挡、点数不足、角度不利 | 绝对位置中断 | 机载短时传播和安全降级 |
| 高反射物误检 | 环境存在其他反射目标 | 错误位置观测 | 几何、轨迹和视觉联合判别 |
| 多机身份交换 | 目标交叉或遮挡 | 控制对象错配 | 多模态身份和一致性检查 |
| 时间同步错误 | 时钟偏差或时间戳语义错误 | 融合和控制滞后 | 统一时钟和延迟估计 |
| 把到达时间当作测量时间 | 驱动或 ROS 2 覆盖设备时间戳 | 高动态时观测错位 | 分别记录采样、接收和输出时间 |
| 外部里程计重置或冻结 | VIO/LIO 重启、退化或消息重复 | 位置跳变或控制持续使用旧状态 | 重置计数、序号、超时和跳变检查 |
| 多定位源相关性被忽略 | 共用原始测量或同一 IMU | 估计器过度自信 | 记录观测来源并验证融合拓扑 |
| 通信中断 | 干扰、拥塞或链路故障 | 外部观测失效 | 机载超时与降级策略 |
| 撞击导致外参变化 | 结构或安装变形 | 定位系统性偏差 | 结构验证和健康检测 |
| 地面站共同故障 | 供电、传感器或计算故障 | 多机同时失去支持 | 冗余或明确失效策略 |

当前缺少规则、场地和实验数据，不能可靠评定风险优先级。
