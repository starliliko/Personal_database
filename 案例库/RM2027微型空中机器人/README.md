# RM2027微型空中机器人技术案例

这个案例来自一次关于 RoboMaster 2027 微型空中机器人的讨论。

讨论最初只是几个很实际的问题：比赛场地的光流是否可靠？机载视觉惯性导航会不会太重、漂移太大？如果超宽带定位不能使用，能否把定位设备搬到雷达站？无人机还要承受撞击时，重量应该怎样分配？

把这些问题放在一起后，逐渐形成了一个候选系统架构。

- 当前成熟度：**L0 想法**
- 当前用途：保存系统推理和待验证问题
- 尚未完成：官方规则核对、论文调研、参数计算和实验验证

## 要解决的问题

在微型无人机重量、算力、防护和场地条件都受到限制时，如何获得全场定位，同时支持实时飞行控制和多机身份识别？

## 为什么常见方案都不轻松

- 光流很轻、频率高，但依赖地面纹理、光照和高度，也不能自然提供长期绝对位置。
- D430 加 CM5 运行视觉惯性导航具有较强自主性，但重量、功耗、散热和大场地累计漂移仍需验证。
- 讨论认为超宽带定位不被规则允许，但尚未找到正式条款。
- 外部视觉和激光雷达可以减轻机载负担，却会引入遮挡、视场、标定、延迟和外部设施依赖。

## 当前候选架构

```text
雷达站：激光雷达 + 双目工业相机 + 多目标处理
                         ↓
                 外部位置 / 姿态 / 身份观测
                         ↓
                   通信与时间同步
────────────────────────────────────
                         ↓
无人机：惯性测量 + 光流 → 状态估计 → 实时飞控
```

核心思想是：把重感知和重计算放在地面，把高频状态传播、控制和安全闭环保留在机载端。无人机表面的高反射标记可能帮助激光雷达识别目标，双目视觉则作为姿态和身份信息的候选补充。

## 最值得关注的风险

- 单个雷达站的遮挡和视场死角；
- 远距离目标的激光雷达点数不足；
- 场地高反射物造成误检；
- 多架无人机交叉时身份关联错误；
- 远距离视觉姿态可观测性不足；
- 时间同步、通信延迟、丢包和失联；
- 光流对场地纹理的依赖；
- 撞击导致结构或传感器外参变化。
