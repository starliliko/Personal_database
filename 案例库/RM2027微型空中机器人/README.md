## 案例概述

讨论从几个互相冲突的条件开始：场地光流不一定可靠；机体需要考虑 42 毫米弹丸撞击；机载重量和算力有限；讨论认为超宽带定位不可用；机载视觉惯性导航可能在大场地漂移。

由此逐渐形成一个候选架构：把激光雷达、双目工业相机和重计算放在雷达站；无人机端保留飞控、惯性测量、光流和实时控制；通过高反射标记识别无人机，并把外部观测与机载信息融合。

这个方案参考了 Swarm-LIO2 使用高反射特征识别无人机的思路，但并不是原版 Swarm-LIO2。当前最重要的价值是保留“约束如何推动架构形成”的过程，以及暴露所有尚未回答的问题。
