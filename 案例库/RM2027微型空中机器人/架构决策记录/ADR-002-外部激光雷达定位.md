# ADR-002：外部激光雷达定位

- 状态：提议中
- 日期：2026-08-24
- 适用案例：[RM2027微型空中机器人](../README.md)
- 灵感来源：Swarm-LIO2 中利用高反射特征识别无人机的思路

## 背景

仅靠光流无法自然提供长期绝对位置；机载视觉惯性导航可能受到重量、算力、纹理和累计漂移影响；讨论认为超宽带定位不可使用。因此需要寻找一种机载负担较轻的外部绝对定位候选方案。

## 当前决策

在无人机上布置激光雷达高反射标记，由雷达站的 Mid-70、Avia 或 HAP 等候选激光雷达进行检测和位置观测。双目长焦全局快门相机作为姿态和身份信息的候选补充。

## 选择理由

- 主要传感器和计算不占用机载重量；
- 高反射特征可能简化目标从环境点云中的提取；
- 激光雷达与视觉信息可能在位置、姿态和身份上互补；
- 可以与机载惯性测量和光流形成高低频融合。

## 代价与风险

- 远距离目标有效点数可能不足；
- 反射强度受材料、入射角和距离影响；
- 单站视场和遮挡可能无法覆盖全场；
- 场地其他高反射物会造成误检；
- 多机交叉时可能发生身份交换；
- 双目视觉提供姿态和身份的能力尚未证明。

## 与 Swarm-LIO2 的边界

本决策只借用了高反射目标识别的灵感。当前系统是固定雷达站观测微型无人机的集中式外部定位，不等同于 Swarm-LIO2 原始架构，也不能用原方案的结果直接证明本方案可行。

## 推翻条件

- 官方规则不允许高反射标记或相应外部传感器；
- 目标距离上的点数和回波不足以稳定定位；
- 遮挡和误检无法通过多传感器处理解决；
- 更简单的外部视觉或机载方案已经满足指标。

## 验证要求

- [ ] 核对官方规则
- [ ] 计算候选激光雷达的距离和点密度
- [ ] 进行反射材料角度、距离和动态实验
- [ ] 验证多目标检测和身份保持
- [ ] 测量时间同步、处理和通信延迟
